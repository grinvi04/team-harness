# 표준 문서 정비

## 목표와 승인 범위

공통 표준을 특정 제품의 설계에서 분리한다. 기술 설명은 공식 자료로 연결하고,
실무 관행과 문제 해결 안내는 적용 조건·근거·한계를 짧고 쉬운 문장으로 남긴다.
사용자는 표준 관련 문서 전체의 조사, 공식 자료 보강, 실무 관행 정리와 수정을 승인했다.
이번 작업은 docs와 직접 소비하는 템플릿의 정비다. 새로운 검사 기능을 만들지 않는다.

제품 방향 판정: 공통 계약과 문서 연결은 **소유**, 기술의 사용법은 공식 자료에 **위임**,
제품의 인증 공급자·데이터 모델·호스팅 선택은 해당 프로젝트에 **위임**한다.

## 변경 경계

- 대상: README의 표준 안내, 기술·운영·UI 표준, 직접 연결 문서와 스택 규칙 9개.
  PR 템플릿과 QA의 한국어 표시 안내도 직접 소비자로 함께 정비한다. QA 실행 권한·방식은 변경하지 않는다.
- 현재 거버넌스의 권한·보호·CI 게이트는 유지한다. 실제 강제 범위보다 큰 설명만 고친다.
- 과거 결정·실행 기록은 보존하고 새 적용 기준으로 연결한다.
- 소비 repo 수정·원격 작업, 머지, 릴리즈, 설치, 배포, 결제는 범위 밖이다.
- 로컬 정비 이후 사용자가 이 브랜치 push와 develop 대상 Draft PR 생성을 추가 승인했다.
- 전역 지침·모델 설정·스킬 설정과 Claude 인증·실제 모델 시험은 변경하지 않는다.
- 기존 사용자 작업공간은 보존한다. 앱이 만든 fix/standards-refresh 작업공간에서 수정한다.
