## 범위와 수용 기준

- 제품 방향은 **소유**: 공용 CI·증거의 신뢰성을 유지하는 기존 결함 수정이다.
- CI에 ripgrep 설치를 명시하고 실제 버전을 출력한다.
- 검색 종료0은 금지 문자열 발견으로 실패, 종료1만 문자열 없음으로 통과한다.
  종료2·127 등 실행 오류는 검사 실패로 처리한다. 파이프 양쪽의 오류를 보존한다.
- 기존 비밀값·Codex/Claude 격리·보고서 검사와 fixture는 유지한다.
- 실행 오류를 주입하는 회귀가 수정 전 RED, 수정 후 GREEN이어야 한다.
  영향 검사·문서 구조·현재 PR 전체 CI·독립 검토를 통과한 뒤 릴리즈를 재개한다.
- 사용자 primary·다른 worktree·전역 설정은 변경하지 않는다. Claude 인증·실제 모델
  검증·소비 원격 작업·배포·결제는 계속 제외한다.
