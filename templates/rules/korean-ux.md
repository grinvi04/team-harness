# 한국어 화면 작업 규칙

한국어 화면에만 적용한다. 제품에서 정한 톤·용어·지원 사용자를 따른다.
쉬운 문장과 결과를 예상할 수 있는 행동 이름을 쓴다. 실패에는 가능한 다음 행동을 안내한다.
아이디·이름·청구서 등은 의미를 확인한다. 서로 다른 개념을 한 단어로 합치지 않는다.
삭제 경고는 실제 복구 가능성에 맞춘다. 날짜·전화·금액은 지원 범위와 API 계약을 확인한다.
원 단위 표시가 내부 계산의 소수점 제거를 뜻하지 않는다.
정보 밀도·필터·합계 행·토스트·버튼 위치는 제품의 과제로 정한다. 특정 업무 화면을 강제하지 않는다.
공통 안내는 Team Harness `docs/korean-ux.md`, 적용 기준은 `docs/standards-scope.md`다.
